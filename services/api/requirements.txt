# Requires Python >= 3.11 (see docs/TASKS.md task 0.2).
# The shared domain package (scam taxonomy, victim-state schema, Hinglish
# markers). REQUIRED: engine/classifier.py and ingest/language.py import it, and
# their ImportError fallbacks are deliberately incomplete — an empty BY_LABEL
# means threat weighting is silently lost. services/api/tests/test_domain_imports.py
# asserts the real package is the one serving.
-e ./packages/aegis_core

# Runtime API. Everything below the first block is optional — the service
# starts and answers without any of it, in a measurably worse mode that
# /api/health reports honestly.
fastapi>=0.115
uvicorn[standard]>=0.30
pydantic>=2.8
# Typed, validated settings with declarative PRESAGE_* -> AEGIS_* aliases.
# Config errors then fail at startup naming the field, not later and elsewhere.
pydantic-settings>=2.4
python-multipart>=0.0.9
httpx>=0.27

# Persistence & auth. SQLAlchemy is pure-Python and needs no server for the
# default in-memory mode, so it does not require any setup to run the demo —
# it only enables durable storage when DATABASE_URL is configured. Auth (pbkdf2
# password hashing + HS256 tokens) uses the standard library, no extra dep.
SQLAlchemy>=2.0

# Module 2 (FIGAE) fraud-intelligence graph. Pure-Python, no system libs, no
# server (the PDF named Neo4j; NetworkX runs in-process behind the same
# interface). REQUIRED, not optional: services.api.main imports the intel
# service at startup, so a clean install without this fails to boot — which is
# exactly what CI caught. The old <3.3 cap existed only to keep Python 3.9
# working; the floor is now 3.11, so the cap is gone.
networkx>=3.3

# Test runner. Not optional in practice: the README asks you to run the
# verdict regressions before every push, and a fresh clone that cannot run
# them is a fresh clone whose checks get skipped.
pytest>=8.0

# Court-admissible evidence package as PDF (routes /api/session/{id}/report.pdf).
# Pure-Python, no system libs. The JSON package works without it; the PDF
# endpoint degrades to a clear 503 if it is absent.
reportlab>=4.0

# Optional: serve the fine-tuned MuRIL checkpoint instead of the lexical
# fallback. ~2GB of wheels; skip on a laptop that only needs the demo.
# torch>=2.3
# transformers>=4.44

# Optional: dense retrieval instead of BM25. Downloads a ~90MB model on
# first run, which is why it is not a default.
# sentence-transformers>=3.0

# Optional: OCR for image inputs (screenshots, fake notices, QR). Tesseract is
# the default backend and also needs the `tesseract` system binary
# (`brew install tesseract` / `apt install tesseract-ocr`). Without these the
# /api/analyze/image route degrades to `ocr:unavailable` and asks the user to
# type the text — it never returns a verdict on an empty read.
# pytesseract>=0.3.10
# Pillow>=10.0
