# research/

Everything the paper needs, kept separate from product code so that a change to
the app cannot silently change a published number.

| Directory | Holds |
|---|---|
| `experiments/` | E1–E8 from docs/RESEARCH.md, one module each |
| `ablations/` | The nine-configuration ablation |
| `notebooks/` | Exploration only — nothing here is a result |
| `results/` | Committed JSON. Every number in the paper comes from a file here |
| `paper/` | Manuscript, figures, bibliography |

## The rule

`python -m research.run --experiment N` reproduces its table on a clean clone,
with fixed seeds and fixed splits. **Figures are generated by the harness, never
drawn by hand** — a figure nobody can regenerate is a figure nobody can trust.

Populated in Phase 9. See docs/RESEARCH.md.

## Results

### Experiment 0 — the stage classifier's leak (T-06)

`research/experiments/exp0_stage_classifier_leak.py` →
`research/results/exp0_stage_classifier_leak.json`. Needs the checkpoint;
reads both historical splits from git; re-running reproduces the file byte for
byte (checked under two different `PYTHONHASHSEED`s).

Macro-F1 of the served MuRIL checkpoint and the lexical baseline (cues as they
were at `e123bd5`), cut by whether the checkpoint was trained on the turn:

| Test split | Cut | n | Lexical | MuRIL | Fused |
|---|---|---:|---:|---:|---:|
| `e123bd5` (where 0.767 was measured) | all | 423 | 0.375 | 0.767 | 0.704 |
| | leaked (in its train + val) | 311 | 0.317 | **1.000** | 0.770 |
| | unseen | 112 | **0.431** | 0.300 | 0.393 |
| `85a2aee` (its own test split) | all — none leaked | 171 | **0.372** | 0.221 | 0.422 |

The 0.767 is the checkpoint reciting its training data; on turns it had not
seen it loses to the keyword baseline. Today's lexical cues (after B-08) score
0.414 / 0.356 / 0.454 / 0.372 on the same cuts — a regression figure, not a
clean held-out one (audit D-16). Building this found audit B-12: the fused
model broke ties in a per-process random order.
