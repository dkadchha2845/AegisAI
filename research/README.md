# research/

Everything the paper needs, kept separate from product code so that a change to
the app cannot silently change a published number.

| Directory | Holds |
|---|---|
| `experiments/` | E1–E8 from docs/RESEARCH.md, one module each |
| `ablations/` | The nine-configuration ablation |
| `notebooks/` | Exploration only — nothing here is a result |
| `results/` | Committed JSON. Every number in the paper comes from a file here |
| `paper/` | Manuscript, figures, bibliography |

## The rule

`python -m research.run --experiment N` reproduces its table on a clean clone,
with fixed seeds and fixed splits. **Figures are generated by the harness, never
drawn by hand** — a figure nobody can regenerate is a figure nobody can trust.

Populated in Phase 9. See docs/RESEARCH.md.
