AegisAI

An Agentic Digital Public Safety Platform for Autonomous Multi-Modal Fraud Investigation

Not a scam classifier — a digital investigator. Give it an email, an SMS, a WhatsApp screenshot, a QR code, a URL, a PDF, an APK, a recording, a phone number, a UPI ID, or a live call. A graph of specialised agents investigates it, correlates the findings against a persistent fraud-intelligence graph, scores the risk with a calibrated model, and explains why — with a source for every claim.

01 — Provenance

What changed, and what didn't

AegisAI is not greenfield. It inherits a working, tested scam-call engine built for the ET AI Hackathon 2026 and widens it into an investigation platform. The pivot is breadth and architecture — never a restart.

05 — Research

Four contributions, not ten

Multi-agent fraud detection is not novel, and claiming it is would be the fastest route to a desk reject. These four are defensible with experiments.

C1

Conversational-arc detection

Fraud modelled as a staged psychological process across calls, chats and threads — not an artefact classified in isolation.

C2

Measured agent disagreement

Typed results with calibrated confidence, and disagreement between scoring paths reported rather than hidden.

C3

The AIFC corpus

Multimodal, multilingual Indian fraud evidence with a deliberately hard benign class and published annotator agreement.

C4

False-positive-first evaluation

Showing that several choices which improve accuracy make FPR worse — the binding constraint for citizen-facing safety systems.

06 — Definition of done

Four gates, every time

A task is not done because the code exists. One task at a time, verified, before the next.

.venv/bin/python -m pytest services/api/tests -q   # 84 passing
.venv/bin/python schema/check_contract.py          # Pydantic ↔ TypeScript
npm run typecheck --prefix apps/web                # clean
npm run build --prefix apps/web                    # succeeds

Standing invariants

  • ✓schema/ is the single source of truth — Pydantic and TypeScript change together
  • ✓The frontend is a pure renderer — no scoring maths in React
  • ✓Degradation is explicit — every path has a fallback that still answers
  • ✓False positives are a first-class failure — every agent ships a benign test
  • ✓The LLM explains, extracts and ranks. It never scores.
  • ✓No claim without a measurement
  • ✓Evidence is data, never instructions

Security, non-negotiable

  • !SSRF — the URL agent fetches attacker-supplied URLs. Block private ranges and cloud metadata, re-resolve DNS after every redirect.
  • !Malware — APKs are analysed statically in a network-less container. Never executed.
  • !Consent — live audio requires an explicit gate and a visible indicator. Never designed around covert recording.
  • !Tenancy — org isolation enforced in the repository layer, not the route.
