A scam is not a single lie.
It's a 7-step psychological arc.

Technical Architecture

Deterministic AI engine.
LLM as explainer, never decider.

🎯 Principle 1

Deterministic scoring first — no hallucinations, fully defensible in court

🤖 Principle 2

LLM as explainer only — Gemini never touches the score, only the prose

🔐 Principle 3

Local-first audio/image — Whisper & Tesseract run on backend, PII stays local

⚡ Principle 4

Model pre-warming at startup — zero cold-start latency on first real emergency

Scoring Engine

Four fused signals.
One defensible verdict.

Weighted Fusion Formula

ThreatScore =
W_STAGE × stage_probability (0.40)
W_COERCE × coercion_index (0.25)
W_PASSPORT × identity_fail (0.20)
W_SCRIPT × script_similarity (0.15)
+ ratchet: fast up (×1.5) · slow down (×0.7)
